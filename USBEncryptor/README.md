# USB Encryptor

Классическая портативная Windows-утилита для создания зашифрованных копий файлов.

## Возможности первой версии
- Шифрование выбранных файлов и всех файлов внутри выбранной папки (включая подпапки).
- Расшифровка файлов формата `.usbenc`.
- AES-256-GCM через Windows CNG (BCrypt).
- Получение ключа из пароля с PBKDF2-HMAC-SHA-256 (600 000 итераций).
- Оригиналы не удаляются ни при шифровании, ни при расшифровке.
- Не требует установки, сети, облака, сторонних DLL или .NET Runtime.
- Классический интерфейс Win32 на стандартных элементах Windows.

## Сборка
GitHub Actions собирает x64 EXE с MSVC и статической CRT (/MT). Результат публикуется как артефакт `USBEncryptor-Portable-x64`.

## Ограничения первой версии
- Обрабатываются файлы размером до 512 MiB каждый.
- При шифровании рядом с исходником создаётся файл с расширением `.usbenc`.
- При расшифровке создаётся отдельный восстановленный файл; зашифрованный файл остаётся.
- Папки обрабатываются пофайлово: для каждого файла создаётся отдельная зашифрованная копия.
- Пароль должен содержать не менее 8 символов. Потерянный пароль восстановить нельзя.

## Важная осторожность
Это первая версия проекта, поэтому сначала проверяйте её только на тестовых копиях файлов. Не используйте её как единственную защиту важных данных, пока программа не прошла независимую проверку и полноценное тестирование. Не забывайте пароль.

Программа не создаёт собственных логов или файлов настроек. Однако Windows и защитное ПО могут сохранять сведения о запуске; абсолютное отсутствие следов на компьютере не гарантируется.
